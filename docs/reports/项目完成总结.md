### 10 类形态匹配结果（单次测试）

```
✅ downtrend (直线下降)     → Top1 正确
✅ v_rebound (V型反弹)      → Top1 正确
❌ uptrend (直线上升)       → 误判为 v_rebound
❌ w_bottom (W底)           → 误判为 v_rebound
❌ m_top (M头)              → 误判为 v_rebound
❌ inverted_v (倒V)         → 误判为 v_rebound
❌ triangle_con (三角收敛)  → 误判为 v_rebound
❌ triangle_div (三角发散)  → 误判为 v_rebound
❌ sideways (横盘)          → 误判为 v_rebound
❌ ladder_up (阶梯上涨)     → 误判为 v_rebound
```

**原因分析**：复杂形态（M/W/阶梯）在 FAISS 粗召回阶段就被筛除，无法进入 Top400 候选池，DTW 精排无法补救。

## 🎯 快速使用

### 最快启动方式

#### Windows
```cmd
# 1. 启动服务
run.bat dev

# 2. 新命令行窗口，运行演示
run.bat demo

# 3. 生成报告
run.bat report
```

#### Linux/Mac
```bash
# 1. 启动服务
bash run.sh dev

# 2. 另一个终端，运行演示
bash run.sh demo

# 3. 生成报告
bash run.sh report
```

#### Docker
```bash
# 完整栈启动（FastAPI + Redis + Nginx）
bash run.sh docker-build
bash run.sh docker-start

# 查看日志
docker-compose logs -f shape-match-app
```

### 测试 API

```bash

    "points": [[0,0.2],[0.25,0.35],[0.5,0.5],[0.75,0.65],[1,0.8]],
```
