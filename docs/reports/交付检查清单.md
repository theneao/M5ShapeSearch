## 🎓 后续优化 (P0 优先级)

基于当前 20% 的准确率，建议按以下优先级优化：

### 优化方向 ① (最直接)
```
增加样本量：per_type_count 120 → 200
增加增强：augment_per_clean 6 → 10
预期：准确率 20% → 40-50%
```

### 优化方向 ② (加权调优)
```
调优向量权重：
  peak_weight: 50 → 60
  valley_weight: 50 → 60
  block_weight: 3 → 2.5
预期：复杂形态区分度提升 20-30%
```

### 优化方向 ③ (索引升级)
```
替换索引算法：
  IndexFlatIP → FAISS IVF-PQ
  或 二级索引 (简单/复杂分桶)
预期：复杂形态召回率 0% → 30-50%
```
