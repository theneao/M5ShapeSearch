## 1. 项目双端架构

| 端 | 技术栈 | 位置 | 状态 |
|----|--------|------|------|
| 硬件端（手表） | ESP-IDF + LVGL，M5Stack 类固件 | `main/`（根目录） | Shape Search + 整机 Settings 已完成并通过构建 |
| **云服务端（本次主线）** | Python 3.11 + FastAPI + FAISS + numpy | `server/` | MVP 完成，准确率待优化 |
| 方案文档 | Markdown | [`../design/技术形态搜索系统实施方案.md`](../design/技术形态搜索系统实施方案.md)（V2.0，9 章） | 与代码同步更新中 |

核心流水线（两端对齐，[shape_features.py](../../server/core/shape_features.py) 是唯一真源）：

```
手绘/真实K线(≈60点)
 → 移动平均去抖(3)
 → RDP Douglas-Peucker 压缩(ε=0.008)
 → 128点等距重采样
 → Min-Max 归一化
 → 16维统计 ShapeStats16
 → 303d向量 build_303d_vector（v3 权重版）
 → FAISS IndexFlatIP 9桶 粗召回(Top400×桶, recall_multiplier=40)
 → 内存硬规则过滤（峰谷±2 / 趋势>±0.01 / 位移>±0.1）
 → 32点 Classic-DTW + Sakoe-Chiba band=3 精排 Top30
 → 融合分 0.72×DTW + 0.28×cos → TopK 返回
```

## 5. 交互式 UI + 数据源（本期主线，已完成）

### 5.1 参数面板（去掉预制假数据概念）

用户要求去掉"每形态干净样本数/手绘扰动倍数"这类**预制假数据概念**，改成**只控制标的池数量**：

- `build_dataset_from_symbol_pool` 统一入口按标的池 N 构建，`data_source` ∈ `MOCK / AKSHARE / BINANCE / TUSHARE`
  - `MOCK`：内部把 N×274 窗口目标映射到 `generate_samples`（UI 不暴露预制概念）
  - `AKSHARE`：**真实多资产，无需 Key（本期新增，推荐）**
  - `BINANCE`：public klines，无需 Key
  - `TUSHARE`：需 `TUSHARE_TOKEN` 环境变量
  - 真实数据滑窗：`_slice_ohlcv_to_samples` 60窗口/步长10，shape_type 用**弱分类标注**（峰谷趋势启发式，非真值）
- 匹配结果有 **TopK 投票形态**，并注明真实数据下形态名仅为弱标注

### 5.2 网页交互式演示 UI（简化版，推荐日常使用）

`interactive_demo_simple.py`：三栏布局 **参数设置 → 手绘画板 → 匹配结果**。
隐藏随机种子等无关参数，聚焦真实数据流程：选数据源 → 点 **Build Data** 拉真实 K 线构建索引 → 画板手绘 → 松手自动匹配 Top10（对比图 + 结果表 + 匹配统计）。

`start_all.py` **一键启动**：同时拉起 FastAPI(8000) 与 Gradio UI(7860)，双线程实时打印 `[API]` / `[UI]` 前缀日志；端口占用自动 +1 递推。
（注意：`interactive_demo_simple.py` 自带 `find_free_port(7860)`，start_all 传入的 `GRADIO_SERVER_PORT` 目前未被读取，仅 UI 自寻端口，不冲突。）

### 5.3 AKShare 数据源细节（本期新增）

`core/real_data_builder.py::_fetch_akshare_ohlcv`：
- **股票** `ak.stock_zh_a_daily`（**新浪源**，前复权日线）：pool 代码 `SH:600519` → 转 `sh600519`
- **期货** `ak.futures_main_sina`（新浪源，**主力连续合约**）：pool 代码 `SHFE:CU2410` → 取品种 `CU0`
- **加密货币**：AKShare 当前版本无历史 K 线接口 → `build_dataset_from_symbol_pool` 内 fallback 到币安 public API
- ⚠️ **网络约束**：本机东财接口（`push2his.eastmoney.com`，即 `stock_zh_a_hist` 的数据源）**不可达**（无论代理/直连均连接重置），
  因此股票必须用新浪源；币安 API 需走系统代理 `127.0.0.1:7897` 才能访问（详见 memory：`network-constraints`）。
- ⚠️ 实现细节：先 `sort_values` → `tail(limit)` → `reset_index(drop=True)`，否则 `df.at[i,...]` 报 KeyError。

**AKSHARE 端到端实测（已验证）**：3×3 标的池（3 股 + 3 期货 + 3 币）→ 1695 条形态，构建 21.7s；
FAISS 9 桶（stock_1d=705 / futures_1d=705 / crypto_1d=285）索引 + 手绘搜索全流程正常。

### 5.4 手绘报错修复

Gradio `Sketchpad` 的 `change` 回调返回的是 **dict**（`{'background': Image, 'composite': Image}`）而非 PIL Image，
直接 `.convert()` 报 `'dict' object has no attribute 'convert'`。`_sketch_to_points` 已加 `isinstance(sketch_img, dict)`
分支，从 `'composite'` / `'background'` 键提取 Image 再处理（`interactive_demo_simple.py` 与 `interactive_demo.py` 均已修复）。

## 6. 已知技术坑（务必保留）

1. **PSReadLine 控制台 Bug**：Windows PowerShell 下长命令含中文/emoji/多引号嵌套会崩
   （`System.ArgumentOutOfRangeException top=-11`）。对策：写临时 .py 文件再执行，不在命令行内嵌长脚本。
2. **终端中文乱码**：stdout 的 emoji/中文显示为"锔忊儯"，数字可读。对策：断言结果看数值，
   或 `$env:PYTHONIOENCODING='utf-8'` + 输出重定向到文件再 Read。
3. **依赖版本锁**：numpy 必须 `<2`（faiss 兼容），faiss-cpu `>=1.9.0`；pip 用清华镜像
   `--index-url https://pypi.tuna.tsinghua.edu.cn/simple`。
4. **时延优化关键**：`FaissIndexManager` 构建时一次性写入 `_stats_cache/_seq_cache/_vec_cache`
   三个内存字典，搜索 O(1) 取，消除 SQLite 每次 IN 查询 155ms 磁盘 IO 瓶颈。
5. **DTW 提速关键**：Soft-DTW 纯 Python 50 次=10.46s → 改 32 点重采样 + band=3 Classic-DTW → <6ms（提速~1700x）。
6. **tests 需为 Python 包**：`tests/__init__.py`、`tests/mock/__init__.py` 空文件必须存在。
7. **Windows 无 gunicorn**：requirements.txt 用 `sys_platform != "win32"` 条件安装，Windows 用 uvicorn。
8. **emoji 不要写进代码输出/日志**（会触发第 1、2 条），状态文本用 `[OK]/[ERR]/[WARN]` 前缀。
9. **Gradio Sketchpad 返回 dict**：`sketch.change()` 回调输入是 `{'background': Image, 'composite': Image}`，
   必须先 `isinstance` 判断再取键，否则 `.convert()` 报 `'dict' object has no attribute 'convert'`（详见 §5.4）。
10. **东财接口在本机不可达**：`ak.stock_zh_a_hist`（东财源）无论代理/直连均连接重置 → A股统一用新浪源
    `stock_zh_a_daily`（symbol 需小写前缀，如 `sh600519`）。币安 API 需走系统代理 `127.0.0.1:7897`。
11. **Windows 终端编码**：脚本入口加 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')`
    （`start_all.py` / 各 UI 已内置），否则中文日志 GBK 报错。
