# 服务端一键启动

- 修改时间：2026-08-31
- 作用：说明 `server/start_all.py` 的进程、端口、日志与停止行为。

## 启动

```powershell
conda activate shape-server
cd D:\py_code\M5ShapeSearch\server
python .\start_all.py
```

启动器会同时管理两个子进程：

| 服务 | 默认地址 | 用途 |
|---|---|---|
| FastAPI | `0.0.0.0:8000` | 手表和网页使用的唯一计算接口 |
| Unified UI | `127.0.0.1:7860` | PC 手绘、Top-K、详情 K 线、行情参数、刷新和运行看板 |

8000 必须可用，否则启动失败。Gradio 首选端口若已被占用，会自动顺延并在终端打印实际地址。

## 日志与进度

- 行情加载以终端单行进度条显示，避免逐标的成功日志刷屏。
- 选池、限流、重试、异常、缓存提交和匹配耗时仍会输出。
- 统一页面的运行状态标签同步显示刷新阶段、周期桶数量、末根 K 线时间和最近异常。
- 启动提示完成后若暂时没有新日志，通常表示服务正在正常等待请求。

## 行情缓存行为

- 启动时先加载本机 NPZ 缓存，手绘请求直接搜索内存数据。
- 后台按最小启用周期检查末根 K 线时间；不是按每次手绘重新下载。
- 未缓存周期的搜索返回 `202 DATA_BUILDING`，服务端继续构建，手表可等待或取消等待。
- A 股由 AKShare 获取，Crypto 使用 Binance 公开市场数据接口；不需要账户 API Key。

## 局域网连接

手表不能访问电脑的 `127.0.0.1`，应使用启动器输出的 `Hardware/LAN` 地址。若手机访问健康检查也失败，应检查：

1. 电脑和手表是否连接同一个 2.4 GHz 网络。
2. Windows 防火墙是否允许 Python 监听专用网络的 TCP 8000。
3. 路由器或手机热点是否启用了客户端隔离。

## 停止

在启动器终端按 `Ctrl+C`。启动器会依次停止 API 和统一网页子进程，并保存当前索引状态。
