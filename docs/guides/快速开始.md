# M5ShapeSearch 快速开始

- 修改时间：2026-08-31
- 适用范围：ESP-IDF 固件、本地 FastAPI 服务和统一 Gradio 页面。

## 1. 准备环境

- ESP-IDF 5.5.5
- Python 3.11
- Windows PowerShell；Linux/macOS 可使用等价命令

服务端推荐使用独立 Conda 环境：

```powershell
conda create -n shape-server python=3.11 -y
conda activate shape-server
cd server
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

## 2. 启动服务端

```powershell
cd D:\py_code\M5ShapeSearch\server
python .\start_all.py
```

启动完成后终端会给出：

- API 与健康检查地址（固定端口 8000）
- 局域网硬件可访问的 `Hardware/LAN` 地址
- 统一 Web UI 实际地址（首选端口 7860，包含手绘、数据设置和运行看板）

先在同一网络的手机上打开 `http://电脑局域网IP:8000/api/v1/health`。若能看到 JSON，手表才能使用该地址。

## 3. 配置手表网络

进入 `Settings -> WiFi / Server`，开启 `M5Shape-*` 配置热点。手机连接后若未自动弹出门户，打开 `http://192.168.4.1`，填写 Wi-Fi 和服务器地址。

首次本地编译若需要预置网络，可复制私有配置示例：

```powershell
Copy-Item main\apps\app_stock_selector\private_config.example.h `
  main\apps\app_stock_selector\private_config.h
```

填写后的文件只保留在本机，不进入 Git。手表成功提交的配置会写入 NVS，断电后保留。

## 4. 构建与刷机

```powershell
idf.py build
idf.py -p COM5 flash monitor
```

主固件输出为 `build/M5ShapeSearch.bin`。实际串口号可在设备管理器或 ESP-IDF 扩展中确认。

## 5. 基本使用

1. 启动服务端并等待所选周期缓存就绪。
2. 在手表 `Shape Search` 页面绘制形态。
3. 按 B 提交；按 A 或左滑可取消、返回。
4. 点击结果卡片查看命中区间 K 线，详情页的 `+ / -` 可缩放。
5. 在 `Settings -> Market Data` 修改周期、选池、排序、数量和多尺度参数。

## 6. 验证

```powershell
cd server
python -m compileall -q .
python -m pytest -q
```
