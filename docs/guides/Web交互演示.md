# Web 交互演示

- 修改时间：2026-08-31
- 作用：说明 PC 浏览器 7860 统一页面中的手绘调试、数据设置与运行看板。

## 手绘调试页

打开启动器打印的 Unified UI 地址，通常为 `http://127.0.0.1:7860`，进入“手绘匹配”标签。

1. 选择数据类别和一个 K 线周期。
2. 在画布中从左向右绘制走势。
3. 设置返回数量并执行匹配。
4. 在对比图和 Top-K 缩略图中检查红色手绘线与蓝色命中窗口。
5. 在结果表查看综合相似度、NCC、RMSE、相关系数、标的代码和命中根数。
6. 选择单个结果查看该命中区间的真实 OHLC K 线。

匹配不会先把图形归入固定的“上涨、M 头”等类别。综合分是排序分数，不是概率；判断质量时应同时观察缩略图和各分项指标。

## 数据设置页

仍在 `http://127.0.0.1:7860`，切换到“市场数据”或“运行状态”标签；不再单独启动 7861。

可配置：

- 多选周期：`5m / 15m / 30m / 60m / 4h / 1d / 1w`
- 特征窗口、每标的最新 K 线根数、自适应多尺度
- A 股板块、排序字段、前/后 N
- Crypto 计价资产、排序字段、前/后 N
- Binance 请求间隔、每分钟权重预算、并发和重试

数量为 `0` 表示使用全部候选，可能显著增加刷新时间。保存并刷新后，服务端在后台构建并原子替换缓存；旧缓存会持续服务，不会因一次数据源失败而清空。

## 常见状态

- `READY`：该周期已有可搜索缓存。
- `BUILDING`：正在下载或计算，可继续等待。
- `NO_NEW_KLINE`：已检查但末根 K 线时间未推进，无需替换缓存。
- `INCOMPLETE`：某个数据源未完整返回，旧缓存保留，稍后按刷新间隔再检查。
