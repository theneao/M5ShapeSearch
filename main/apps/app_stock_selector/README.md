# 硬件形态选股应用

- 创建时间：2026-08-28
- 修改时间：2026-09-15
- 作用：在 M5ShapeSearch 手表端（ESP32-S3、466×466 AMOLED）提供手绘曲线、服务端形态匹配、组合策略筛选、结果列表和单标的 K 线详情。
- 计算边界：设备只做触摸采样、点压缩、HTTP 请求和 LVGL 绘制；NCC、Turning Point、ShapeDTW 全部由 `server/` 执行。
- 使用：启动 `server/start_all.py` 后打开手表中的 `Shape Search`。整机 `Settings` 下提供独立的 `WiFi / Server` 与 `Market Data` 两个选项页；顶部网络状态只读显示，不再进入应用内设置页。
- 数据页交互：A/B 调整当前值，`PREV FIELD / NEXT FIELD` 显式切换字段，触屏左右箭头同样调值，`APPLY + REFRESH` 保存并让服务器后台刷新；屏幕 `BACK`、左滑或双键长按均可离开。
- 手机配置：在 `WiFi / Server` 页启动 `M5Shape-*` 热点，手机连接后会触发系统配置门户；也可打开 `http://192.168.4.1`，通过 Wi-Fi、Market Data、Advanced 三个标签设置网络、行情参数和服务器 URL。
- 默认与持久化：NVS 为空时可从被 Git 忽略的 `private_config.h` 写入本机首次配网默认值；配网页面成功提交 Wi-Fi 与服务器 URL 后立即写入 NVS，断电不丢失，也不会被默认值覆盖。
- 交互：右侧 B 键负责匹配/进入 Top1/放大，左侧 A 键负责退出、返回或取消；详情与结果页支持左滑返回，等待匹配或详情时左滑取消，双键长按返回启动器。
- 策略：绘图页 `SAVE` 把当前曲线保存到服务器，`FILTER` 进入策略页；触屏多选 Sequoia-X 预设或已保存手绘策略，`MODE: AND/OR` 选择交集/并集，B 键执行，勾选与模式切换只刷新局部控件。
- 网络：顶部 WiFi 图标显示信号等级和 dBm；RSSI `≤-70 dBm` 延长超时，`≤-80 dBm` 再次延长。匹配基础总超时 30 秒、详情 20 秒，超时后明确提示 WiFi/服务器问题并停止等待。
- K 线详情：匹配与详情请求使用独立短连接，避免用户停留后复用已被服务器回收的 keep-alive socket；详情 GET 若遇连接或响应头错误会用全新连接自动重试一次。
- K 线缩放：详情页 `+/-` 在 8 根至全部 K 线之间按比例缩放，中间实时显示“可见根数/总根数”；缩放后仍可左右拖动历史窗口。
- 周期：设备与服务器统一支持且可多选 `5m / 15m / 30m / 60m / 4h / 1d / 1w`；旧 `1h` 自动映射到 `60m`。匹配请求使用紧凑响应，ShapeDTW 路径与诊断数据不会传到设备端。
- 完整数据参数：端侧可配置多周期、窗口、拉取根数、多尺度、刷新检查周期、A 股板块/数量/指标/前后排序，以及 Crypto 数量/指标/前后排序、计价资产和 Binance 限流重试参数；数量 `0` 表示处理全部候选。
- 圆屏布局：所有标题、筛选 Chip、结果卡片、K 线图、缩放按钮和错误提示都位于 466×466 圆形安全区内。
- 策略相关按钮按所在高度的圆屏弦宽单独约束：顶部入口位于 `x=88..378`，底部操作区位于 `x=84..382`，不会再被左右圆角裁切。
- 稳定性：硬件策略筛选固定请求并渲染 Top10；HTTP 工作任务使用 16 KB 栈，并在策略请求前后输出片内堆、最大连续块、PSRAM 和任务栈最低余量；请求资源不足时返回失败提示而不是继续到复位。
